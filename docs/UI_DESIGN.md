# UI 设计规范文档

## 1. 设计原则

### 1.1 设计理念
- **移动端优先**：所有设计以移动端触控体验为核心，桌面端作为适配补充
- **轻量化**：界面简洁，信息层级清晰，减少视觉干扰
- **一致性**：统一的色彩体系、圆角规范、间距系统和交互反馈

### 1.2 目标平台
- 移动端浏览器优先（iOS Safari、Android Chrome）
- 支持微信内置浏览器
- 桌面端响应式适配

---

## 2. 色彩体系

### 2.1 主色调（浅绿色系）

| 用途 | 色值 | 说明 |
|------|------|------|
| 页面背景（浅色） | `#E8F5C8` | 主页面背景色 |
| 页面背景（亮色） | `#F2F8E0` | 卡片/表单背景色 |
| 深色区域 | `#1A1A2E` | 导航栏、深色卡片背景 |
| 强调色 | `#C8E64E` | 按钮、进度条、高亮元素 |
| 强调色（暗） | `#A8C43A` | 渐变末端、次级高亮 |

### 2.2 功能色

| 用途 | 色值 | 说明 |
|------|------|------|
| 成功 | `#00B578` | 操作成功提示 |
| 警告 | `#FF8F1F` | 警告信息 |
| 错误/危险 | `#FF3141` | 错误提示、删除操作 |
| 链接/操作 | `#1677FF` | 可点击元素 |
| 信息 | `#1677FF` | 提示性信息 |

### 2.3 中性色

| 用途 | 色值 | 说明 |
|------|------|------|
| 一级文字 | `#1A1A2E` | 标题、重要文字 |
| 二级文字 | `#666666` | 正文内容 |
| 三级文字 | `#999999` | 辅助说明、时间戳 |
| 四级文字 | `#CCCCCC` | 占位符 |
| 分割线 | `#EEEEEE` | 列表分隔线 |
| 浅灰背景 | `#F5F5F5` | 次级背景 |

### 2.4 渐变规范
- 导航栏渐变：`linear-gradient(135deg, #C8E64E 0%, #A8C43A 100%)`
- 按钮渐变：`linear-gradient(135deg, #C8E64E 0%, #A8C43A 100%)`
- 分割线渐变：`linear-gradient(to right, #C8E64E, transparent)`

## 3. 字体规范

### 3.1 字体族
- 首选：系统默认字体（`-apple-system`, `BlinkMacSystemFont`, `PingFang SC`, `Helvetica Neue`）
- 等宽字体（代码）：`Fira Code`, `Consolas`, `monospace`

### 3.2 字号层级

| 层级 | 字号 | 行高 | 字重 | 用途 |
|------|------|------|------|------|
| H1 | 26px | 1.3 | 700 | 页面主标题 |
| H2 | 20px | 1.4 | 600 | 章节标题 |
| H3 | 17px | 1.4 | 600 | 小节标题 |
| H4 | 15px | 1.4 | 600 | 四级标题 |
| 正文 | 14px | 1.8 | 400 | 主要内容 |
| 辅助 | 13px | 1.5 | 400 | 代码、小字说明 |
| 标签 | 11px | 1.0 | 500 | Tag、Badge |

### 3.3 行高规范
- 正文：`1.8`（提升可读性）
- 标题：`1.3-1.4`（紧凑）
- 标签/数字：`1.0`（紧凑对齐）

## 4. 圆角规范

| 场景 | 圆角值 | 示例 |
|------|--------|------|
| 小按钮/标签 | `4px` | Tag、Badge |
| 输入框/卡片 | `8px` | 表单输入、卡片容器 |
| 胶囊形输入框 | `20px` | 搜索栏、登录页输入框 |
| 大圆角 | `12px` | 弹窗、对话框 |
| 圆形 | `50%` | 头像、圆形按钮 |

---

## 5. 间距系统

基于 4px 基准单位，使用 4 的倍数：

| 间距 | 值 | 用途 |
|------|------|------|
| 极小 | `4px` | 元素内微间距 |
| 小 | `8px` | 列表项间距、按钮内边距 |
| 中 | `12px` | 卡片内边距、表单项间距 |
| 大 | `16px` | 区块间距、页面边距 |
| 极大 | `24px` | 大区块分隔 |
| 超大 | `32px` | 页面级分隔 |

### 5.1 页面布局间距
- 页面左右边距：`16px`
- 导航栏高度：`46px`（NavBar 标准）
- 卡片网格间距：`12px`
- 列表项垂直间距：`8px`

## 6. 组件规范

### 6.1 按钮

**主按钮**
- 背景：渐变 `#C8E64E → #A8C43A`
- 圆角：`20px`（胶囊形）
- 高度：`44px`
- 文字：白色、16px、字重 500
- 阴影：`0 2px 8px rgba(200, 230, 78, 0.3)`

**次按钮**
- 背景：`#F5F5F5`
- 圆角：`20px`
- 高度：`44px`
- 文字：`#1A1A2E`、16px

**文字按钮**
- 无边框、无背景
- 文字颜色：`#1677FF`
- 点击区域最小 `44px`

### 6.2 卡片

**账本卡片**
- 圆角：`12px`
- 背景：渐变色或自定义封面图
- 阴影：`0 2px 12px rgba(0,0,0,0.08)`
- 信息层：深色半透明 `rgba(26, 26, 46, 0.7)`
- 文字颜色：白色

**通用卡片**
- 圆角：`8px`
- 背景：白色
- 边框：`1px solid #EEEEEE`
- 内边距：`16px`

### 6.3 输入框

**标准输入框**
- 圆角：`8px`
- 高度：`44px`
- 边框：`1px solid #EEEEEE`
- 聚焦状态：边框色 `#C8E64E`
- 内边距：`12px 16px`

**胶囊形输入框**（登录页等）
- 圆角：`20px`
- 高度：`48px`
- 背景：`#F5F5F5`
- 无边框

### 6.4 标签（Tag）

- 圆角：`4px`
- 高度：`20px`
- 内边距：`0 6px`
- 字号：`11px`
- 背景：`rgba(255, 255, 255, 0.08)`（深色背景下）
- 文字颜色：`rgba(255, 255, 255, 0.6)`

### 6.5 空状态

- 图标大小：`64px`
- 主文字：16px、`#999999`
- 辅助文字：13px、`#CCCCCC`
- 居中对齐，上下间距 `32px`

## 7. 导航规范

### 7.1 顶部导航栏
- 高度：`46px`
- 背景：渐变 `#C8E64E → #A8C43A`
- 文字颜色：白色
- 返回箭头：白色
- 标题：居中、16px、字重 600

### 7.2 底部导航（TabBar）
- 高度：`50px`
- 背景：白色
- 上边框：`1px solid #EEEEEE`
- 图标大小：`24px`
- 文字大小：`10px`
- 激活色：`#C8E64E`
- 默认色：`#999999`

### 7.3 侧边栏（文档中心等）
- 宽度：`260px`
- 背景：`#1A1A2E`
- 分类间距：`4px`
- 子项左缩进：`32px`
- 激活态：左侧 `3px` 强调色指示条

---

## 8. 交互反馈

### 8.1 点击反馈
- 点击区域最小 `44px × 44px`（手指触控友好）
- 按下时背景透明度变化或缩放效果
- 过渡时间：`0.15s - 0.2s`

### 8.2 Toast 提示
- 位置：页面中上部
- 背景：半透明黑色 `rgba(0, 0, 0, 0.75)`
- 文字：白色
- 圆角：`8px`
- 显示时间：`2s`（成功）、`3s`（错误）

### 8.3 加载状态
- 骨架屏：浅灰色块占位
- Loading 动画：主题色旋转圆环
- 加载文案："加载中..."

### 8.4 过渡动画
- 页面切换：淡入淡出 `0.2s ease`
- 折叠展开：`slideDown 0.2s ease`
- 弹窗出现：从底部滑入 `0.3s ease-out`

## 11. 响应式断点

| 断点 | 宽度 | 适配策略 |
|------|------|----------|
| 手机 | `< 375px` | 单列布局，缩小间距 |
| 标准手机 | `375px - 428px` | 标准移动端布局 |
| 平板 | `768px - 1024px` | 双列布局，侧边栏出现 |
| 桌面 | `> 1024px` | 多列布局，最大化利用空间 |

---

## 12. 无障碍要求

- 所有可交互元素最小触控区域 `44px × 44px`
- 文字对比度符合 WCAG AA 标准（4.5:1）
- 表单字段关联 `<label>` 标签
- 图片提供 `alt` 描述文字
- 错误提示同时使用颜色和文字说明

---
