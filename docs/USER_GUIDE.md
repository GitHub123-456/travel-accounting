# 用户使用手册

## 1. 快速开始

旅行记账是一款移动端优先的旅行费用管理应用。你可以用它来：
- 按旅行创建独立账本
- 记录多币种消费
- 多人分账自动计算
- AI 智能语音/图片记账

打开应用后，注册账号即可开始使用。

### 界面风格
应用采用清新的浅绿色主题设计：
- 浅绿色背景（#E8F5C8 / #F2F8E0）
- 深色头部和卡片（#1A1A2E）
- 黄绿色强调色（#C8E64E）
- 登录页采用胶囊形输入框设计，配有自定义 SVG Logo

## 2. 注册登录

### 注册新账号
1. 打开应用，点击「注册」
2. 填写以下信息：
   - 昵称（必填）
   - 邮箱或手机号（至少填一项）
   - 密码（必填）
3. 点击「注册」完成

### 登录
1. 输入邮箱/手机号和密码
2. 点击「登录」

### 忘记密码
1. 在登录页底部点击「忘记密码」
2. 弹出底部弹窗，输入注册邮箱
3. 输入新密码
4. 点击「重置密码」完成

> 注：直接通过邮箱重置密码，无需验证码。

## 3. 创建账本

账本是按旅行组织费用的容器，每次旅行建议创建一个独立账本。

### 创建步骤
1. 在首页点击右下角「+」按钮或网格中的「新建账本」卡片
2. 填写账本信息：
   - **旅行名称**：如"日本东京之旅"
   - **目的地**：如"东京"
   - **开始日期**：旅行出发日
   - **结束日期**：旅行返回日
   - **预算**（可选）：人均预算金额
   - **备注**（可选）：其他说明
3. 点击「创建」

### 账本封面
- 系统会根据目的地自动生成渐变色封面
- 长按账本卡片可上传自定义封面图片

### 搜索账本
- 在首页顶部搜索框输入关键词，可按名称或目的地搜索

## 4. 添加成员

多人旅行时，需要先添加参与人才能使用分账功能。

### 添加步骤
1. 进入账本详情页
2. 点击「成员管理」或设置中的「参与人」
3. 点击「添加成员」
4. 输入成员姓名和备注（可选）
5. 点击确认

### 管理成员
- 点击成员可编辑姓名和备注
- 左滑或长按可删除成员（已有关联交易的成员无法删除）

## 5. 设置汇率

出境旅行时，需要设置当地货币对本币的汇率。

### 设置步骤
1. 进入账本详情页
2. 点击「汇率管理」
3. 选择币种（如 JPY、USD、EUR）
4. 输入汇率值（1单位外币 = ?本币）
5. 保存

### 注意事项
- 汇率以账本为单位独立设置
- 修改汇率后，该币种的所有交易会自动重新计算本币金额
- 建议在旅行开始前设置好常用币种汇率

## 6. 记账方式

### 6.1 手动记账

1. 在账本详情页点击「+」记账按钮
2. 填写交易信息：
   - **金额**：消费金额
   - **币种**：选择消费币种
   - **分类**：餐饮/交通/住宿/购物/门票/其他
   - **时间**：消费时间
   - **地点**（可选）：消费地点
   - **备注**（可选）：补充说明
3. 选择账单类型：
   - **个人账单**：仅自己的消费
   - **共同账单**：多人分摊的消费
4. 共同账单需额外选择：
   - 付款人：谁先垫付的
   - 参与人：哪些人分摊这笔费用
5. 点击「保存」

> 注：账本的所有成员（创建者和参与者）均可编辑账本信息和交易，不限于账本创建者。

### 6.2 AI 智能记账

AI 记账让你用自然语言快速记账，无需逐项填写表单。

#### 文字记账
1. 在账本详情页点击「🤖 AI记账」按钮
2. 在对话框中输入消费描述，例如：
   - "午餐花了80"
   - "打车去机场 150元"
   - "张三付的 大家AA 晚餐300"
   - "买了两杯咖啡 1000日元"
3. AI 会自动解析出金额、分类、币种、付款人等信息
4. 确认无误后点击「保存记账」
5. 如需修改，继续输入补充信息即可

#### 图片记账
1. 点击对话框左侧的「📷」按钮
2. 拍照或选择小票/账单图片
3. AI 会自动识别图片中的消费信息
4. 确认后保存

#### AI 支持的表达方式
| 表达 | 解析结果 |
|------|---------|
| "午餐80" | 金额80，分类餐饮 |
| "打车去机场150" | 金额150，分类交通 |
| "张三付的 大家AA 300" | 共同账单，付款人张三，所有人参与 |
| "住宿两晚 2000日元" | 金额2000，币种JPY，分类住宿 |

## 8. 查看统计

在账本详情页可查看消费统计：

- **人均预算**：预算进度条显示当前用户实际消费占人均预算的比例，标注"我的预算"和"已用x%"
- **全员总支出**：所有成员所有交易的本币总额
- **个人支出**：个人账单总额
- **共同支出**：共同账单总额
- **分类统计**：按餐饮、交通等分类的消费占比
- **币种统计**：按不同币种的消费明细

## 9. 分账结算

分账功能自动计算多人旅行中每人的应付金额。

### 查看分账
1. 进入账本详情页
2. 点击「分账」或「结算」
3. 查看每人的：
   - **应付金额**：按均摊计算应承担的费用
   - **实付金额**：实际垫付的费用
   - **差额**：正数表示多付（别人欠你），负数表示少付（你欠别人）

### 结算操作
- 点击某人的「标记已结清」按钮
- 已结清的成员会显示对应标记

### 分账规则
- 共同账单在所有参与人之间平均分摊
- 付款人自动包含在参与人中
- 未指定参与人的共同账单默认所有成员参与

## 10. 封存账本

旅行结束且所有费用结清后，建议封存账本。

### 封存操作
1. 进入账本设置
2. 点击「封存账本」
3. 确认封存

### 封存效果
- 账本变为只读状态
- 不能新增、编辑、删除交易
- 不能添加、编辑、删除成员
- 不能修改汇率
- 账本列表中显示「已封存」标记
- 可随时解除封存恢复编辑

## 11. 个人中心

在首页右上角点击头像进入个人中心。

### 可管理的信息
- **头像**：点击头像上传新图片
- **昵称**：修改显示名称
- **默认本币**：设置默认记账本币（如 CNY）
- **账号信息**：查看注册邮箱/手机号
- **账本数量**：查看已创建的账本总数

### 退出登录
- 在个人中心底部点击「退出登录」
