产品需求文档（PRD）

1. 项目背景

旅行记账是一个移动端优先的旅行费用追踪应用，旨在帮助用户在多次旅行中管理费用，支持多币种记账和多人分账。随着出境游的普及，旅行者面临多币种消费、多人AA分账等复杂场景，传统记账工具无法满足需求。本产品针对这些痛点，提供一站式旅行财务管理方案。

2. 目标用户

用户类型 描述
个人旅行者 需要记录多币种消费、管理旅行预算
团队出行组织者 需要管理多人共同消费、计算分账
频繁出差人员 需要按行程分类管理费用
背包客/自由行爱好者 需要轻量化、移动端友好的记账工具

6. 业务规则

规则 描述
封存只读 已封存账本不允许新增、编辑、删除交易和成员
均摊分账 共同账单在参与人之间平均分摊
双币存储 所有金额同时存储原币金额和本币金额
汇率联动 汇率变更触发该币种所有交易的本币金额重算
付款人包含 共同账单的付款人自动包含在参与人列表中
默认参与 共同账单未指定参与人时，默认所有成员参与
金额精度 金额使用 decimal(12,2) 存储，确保精度
人均预算 预算字段存储人均金额，详情页显示"我的预算"进度条，展示当前用户实际消费占比
成员编辑权限 账本所有成员（创建者和参与者）均可编辑账本信息和交易
攻略账本联动 更新攻略内容时自动同步关联账本的名称、预算、日期等信息

用户使用手册

1. 快速开始

旅行记账是一款移动端优先的旅行费用管理应用。你可以用它来：

  • 按旅行创建独立账本
  • 记录多币种消费
  • 多人分账自动计算
  • AI 智能语音/图片记账
  • AI 旅行攻略生成

打开应用后，注册账号即可开始使用。

界面风格

应用采用清新的浅绿色主题设计：

  • 浅绿色背景（#E8F5C8 / #F2F8E0）
  • 深色头部和卡片（#1A1A2E）
  • 黄绿色强调色（#C8E64E）
  • 登录页采用胶囊形输入框设计，配有自定义 SVG Logo

2. 注册登录

注册新账号

  1. 打开应用，点击「注册」
  2. 填写以下信息：
    • 昵称（必填）
    • 邮箱或手机号（至少填一项）
    • 密码（必填）
  3. 点击「注册」完成

登录

  1. 输入邮箱/手机号和密码
  2. 点击「登录」

忘记密码

  1. 在登录页底部点击「忘记密码」
  2. 弹出底部弹窗，输入注册邮箱
  3. 输入新密码
  4. 点击「重置密码」完成

注：直接通过邮箱重置密码，无需验证码。

3. 创建账本

账本是按旅行组织费用的容器，每次旅行建议创建一个独立账本。

创建步骤

  1. 在首页点击右下角「+」按钮或网格中的「新建账本」卡片
  2. 填写账本信息：
    • 旅行名称：如"日本东京之旅"
    • 目的地：如"东京"
    • 开始日期：旅行出发日
    • 结束日期：旅行返回日
    • 预算（可选）：人均预算金额
    • 备注（可选）：其他说明
  3. 点击「创建」

账本封面

  • 系统会根据目的地自动生成渐变色封面
  • 长按账本卡片可上传自定义封面图片

搜索账本

  • 在首页顶部搜索框输入关键词，可按名称或目的地搜索

4. 添加成员

多人旅行时，需要先添加参与人才能使用分账功能。

添加步骤

  1. 进入账本详情页
  2. 点击「成员管理」或设置中的「参与人」
  3. 点击「添加成员」
  4. 输入成员姓名和备注（可选）
  5. 点击确认

管理成员

  • 点击成员可编辑姓名和备注
  • 左滑或长按可删除成员（已有关联交易的成员无法删除）

5. 设置汇率

出境旅行时，需要设置当地货币对本币的汇率。

设置步骤

  1. 进入账本详情页
  2. 点击「汇率管理」
  3. 选择币种（如 JPY、USD、EUR）
  4. 输入汇率值（1单位外币 = ?本币）
  5. 保存

注意事项

  • 汇率以账本为单位独立设置
  • 修改汇率后，该币种的所有交易会自动重新计算本币金额
  • 建议在旅行开始前设置好常用币种汇率

6. 记账方式

6.1 手动记账

  1. 在账本详情页点击「+」记账按钮
  2. 填写交易信息：
    • 金额：消费金额
    • 币种：选择消费币种
    • 分类：餐饮/交通/住宿/购物/门票/其他
    • 时间：消费时间
    • 地点（可选）：消费地点
    • 备注（可选）：补充说明
  3. 选择账单类型：
    • 个人账单：仅自己的消费
    • 共同账单：多人分摊的消费
  4. 共同账单需额外选择：
    • 付款人：谁先垫付的
    • 参与人：哪些人分摊这笔费用
  5. 点击「保存」

注：账本的所有成员（创建者和参与者）均可编辑账本信息和交易，不限于账本创建者。

6.2 AI 智能记账

AI 记账让你用自然语言快速记账，无需逐项填写表单。

文字记账

  1. 在账本详情页点击「🤖 AI记账」按钮
  2. 在对话框中输入消费描述，例如：
    • "午餐花了80"
    • "打车去机场 150元"
    • "张三付的 大家AA 晚餐300"
    • "买了两杯咖啡 1000日元"
  3. AI 会自动解析出金额、分类、币种、付款人等信息
  4. 确认无误后点击「保存记账」
  5. 如需修改，继续输入补充信息即可

图片记账

  1. 点击对话框左侧的「📷」按钮
  2. 拍照或选择小票/账单图片
  3. AI 会自动识别图片中的消费信息
  4. 确认后保存

AI 支持的表达方式

表达 解析结果
"午餐80" 金额80，分类餐饮
"打车去机场150" 金额150，分类交通
"张三付的 大家AA 300" 共同账单，付款人张三，所有人参与
"住宿两晚 2000日元" 金额2000，币种JPY，分类住宿

7. AI 旅行攻略

AI 旅行攻略功能可以根据你的需求自动生成详细的旅行规划。

生成攻略

  1. 在首页点击「AI 旅行攻略」入口
  2. 填写攻略参数：
    • 目的地城市：如"重庆"、"东京"
    • 出发地（可选）：如"上海"、"北京"，用于估算往返机票/高铁费用
    • 旅行天数：如 3 天
    • 人数：出行人数
    • 人均预算（可选）：人均预算金额（人民币）
    • 出行类型：休闲游、美食游、文化游等
  3. 点击「生成攻略」，等待 AI 生成

攻略内容

AI 生成的攻略包含以下内容：

  • 每日行程：按时间段安排的活动、地点、交通方式、人均费用和费用明细
  • 往返交通：如填写了出发地，会自动估算往返机票/高铁费用
  • 美食推荐：当地特色餐厅和必点菜品
  • 住宿建议：推荐住宿区域和价位参考
  • 避坑提醒：实用的旅行注意事项
  • 预算预估：按往返大交通、住宿、餐饮、当地交通、门票等分类的人均预算汇总，所有金额统一使用人民币

修改攻略

  1. 在攻略详情页，点击「AI 修改」
  2. 用自然语言描述修改需求，例如：
    • "把第二天改成逛博物馆"
    • "增加一天去周边古镇"
    • "把预算降低到人均 2000"
  3. AI 会根据你的需求重新调整攻略内容

管理攻略

  • 保存攻略：生成后点击「保存」，攻略会存储到你的账号下
  • 查看攻略列表：在攻略页面查看所有已保存的攻略
  • 编辑攻略：点击已保存的攻略可查看详情和修改
  • 删除攻略：左滑或点击删除按钮移除攻略

一键创建账本

  1. 在攻略详情页点击「创建账本」
  2. 系统自动创建关联账本，填入目的地、天数和预算信息
  3. 后续修改攻略时，关联账本的信息会自动同步更新

8. 查看统计

在账本详情页可查看消费统计：

  • 人均预算：预算进度条显示当前用户实际消费占人均预算的比例，标注"我的预算"和"已用x%"
  • 全员总支出：所有成员所有交易的本币总额
  • 个人支出：个人账单总额
  • 共同支出：共同账单总额

  • 币种统计：按不同币种的消费明细

9. 分账结算

分账功能自动计算多人旅行中每人的应付金额。

查看分账

  1. 进入账本详情页
  2. 点击「分账」或「结算」
  3. 查看每人的：
    • 应付金额：按均摊计算应承担的费用
    • 实付金额：实际垫付的费用
    • 差额：正数表示多付（别人欠你），负数表示少付（你欠别人）

结算操作

  • 点击某人的「标记已结清」按钮
  • 已结清的成员会显示对应标记

分账规则

  • 共同账单在所有参与人之间平均分摊
  • 付款人自动包含在参与人中
  • 未指定参与人的共同账单默认所有成员参与

10. 封存账本

旅行结束且所有费用结清后，建议封存账本。

封存操作

  1. 进入账本设置
  2. 点击「封存账本」
  3. 确认封存

封存效果

  • 账本变为只读状态
  • 不能新增、编辑、删除交易
  • 不能添加、编辑、删除成员
  • 不能修改汇率
  • 账本列表中显示「已封存」标记
  • 可随时解除封存恢复编辑

7. 认证方案

7.1 流程

注册/登录 → 服务端生成 JWT → 返回 Token → 客户端存储 localStorage
                                              ↓
后续请求 → Authorization: Bearer <token> → 中间件验证 → 通过/拒绝

7.2 Token 结构

{
  userId: 1,        // 用户ID
  iat: 1234567890,  // 签发时间
  exp: 1234654290   // 过期时间

7.3 安全措施

  • 密码使用 bcryptjs 加盐哈希（salt rounds: 10）
  • Token 有效期可配置（默认 7 天）
  • 前端 401 响应自动清除 Token 并跳转登录

常用查询示例

1. 获取用户的所有账本（按创建时间倒序）

SELECT * FROM account_books 
WHERE user_id = ? 
ORDER BY created_at DESC;

2. 计算账本总支出

SELECT SUM(local_amount) as total_expense 
FROM transactions 
WHERE account_book_id = ?;

3. 获取账本的分账统计

SELECT 
  p.id,
  p.name,
  SUM(CASE WHEN t.payer_id = p.id THEN t.local_amount ELSE 0 END) as paid,
  COUNT(DISTINCT tp.transaction_id) as shared_count
FROM participants p
LEFT JOIN transactions t ON t.payer_id = p.id AND t.account_book_id = ?
LEFT JOIN transaction_participants tp ON tp.participant_id = p.id
WHERE p.account_book_id = ?
GROUP BY p.id;

4. 获取个人参与的共同账单

SELECT t.* 
FROM transactions t
INNER JOIN transaction_participants tp ON tp.transaction_id = t.id
WHERE tp.participant_id = ? AND t.type = 'shared'
ORDER BY t.transaction_time DESC;

5. 获取用户的旅行攻略列表

SELECT id, title, city, days, budget, travel_type, account_book_id, created_at, updated_at
FROM travel_guides
WHERE user_id = ?
ORDER BY updated_at DESC;

6. 运行方式

6.1 环境准备

# 安装 Python 依赖
cd e2e-tests
pip install pytest playwright requests pytest-html

# 安装浏览器
playwright install chromium

# 确保前后端服务已启动
# 后端: cd backend && npm run dev
# 前端: cd frontend && npm run dev

6.2 运行全部测试

cd e2e-tests
pytest --headed --slow-mo=800

6.3 运行单个模块

# 只运行认证测试
pytest test_01_auth.py -v

# 只运行分账测试
pytest test_06_split_bill.py -v

6.4 生成测试报告

# HTML 报告
pytest --html=report.html --self-contained-html

# 自定义报告
python generate_report.py
